Project Overview

This personal portfolio website is engineered from scratch to serve as a high-performance, interactive digital CV and developer showcase. It highlights my core competencies as a Computer Science student and aspiring software engineer, featuring a custom terminal-inspired splash screen, dynamic role rotation, dual dark/light cyberpunk color themes, and a modular architecture optimized for seamless cross-platform accessibility.

Key Features Implemented

  • Responsive Design: Fluid layouts that adapt seamlessly across mobile devices, tablets, and desktop viewports.
  • Dark Mode Theming: Built-in persistent Dark and Light mode engine utilizing CSS custom variables and automatic localStorage synchronization.
  • Interactive Elements: Custom glowing cursor trackers, smooth mouse-tracking tilt effects, and real-time script-driven text rotators.
  • Performance Optimized: Lightweight DOM manipulation, deferred script loading, and rapid Vercel edge deployment assets.
  • Cinematic Splash Screen: Custom terminal boot loader simulation with dynamic progress bar feedback on initial load.

Implementation Challenges

The development process involved several technical hurdles and solutions:

  • State Persistence Across Refreshes: Handling instant theme application prior to DOM full-load to prevent a flash of unstyled dark content in light mode.
  • Cross-Browser Layout Shifts: Ensuring complex CSS grid alignments and custom SVG custom animations remained performant and visually consistent on mobile viewports.
  • Smooth Animation Balancing: Managing multiple concurrent loops (such as the canvas DNA animation, typewriters, and scroll trackers) without affecting frame rates.

Performance Optimizations

To ensure an optimal user experience and fast loading speeds, several strategies were applied:

  1. Hardware-Accelerated Transitions: Utilized CSS transform and opacity layers combined with will-change properties to offload rendering to the GPU.
  2. Asset Minimization & Zero-Framework Bloat: Compressing assets and leveraging vanilla web code for rapid loading.
  3. Edge Caching & Deployment: Hosted via Vercel's global content delivery network for minimal latency and fast global delivery.

Conclusion

The development of this portfolio successfully bridges aesthetic cyberpunk terminal design with rigorous front-end engineering standards.
