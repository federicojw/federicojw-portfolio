Project Overview

Percava is a web platform designed to support a sustainable upcycling initiative that turns patchwork fabric waste (kain perca) into functional products such as upcycled lanyards and cardholders. The website acts as the educational hub linked directly via QR codes printed on physical Percava products, driving awareness on textile waste reduction and Sustainable Development Goals (SDGs).

Key Features Implemented

  • Interactive Impact Counters: Real-time animated number counters driven by JS to showcase textile waste saved and products crafted.
  • SCAMPER Innovation Framework: Dedicated interactive section illustrating product innovation strategies (Substitute, Combine, Adapt, Modify, etc.).
  • Accordion Knowledge Base: Clean expandable FAQ and educational toggle for textile upcycling insights.
  • SDG Commitment Alignment: Structured educational showcase highlighting contributions to SDG 4, SDG 12, and SDG 13.
  • QR Code Educational Integration: Direct dynamic landing integration designed specifically for physical product QR code scans.

Implementation Challenges

Developing Percava required balancing educational depth with sleek user experience:

  • Physical to Digital Bridge (QR Flow): Designing mobile-first layouts optimized for users scanning physical lanyard QR codes under varying screen sizes and connection conditions.
  • Cross-Device Accordion & Navigation Handling: Creating robust flexbox and grid fallbacks for mobile navigation headers and collapsible accordion panels without external frameworks.
  • High-Contrast Aesthetic Sustainability: Crafting an elegant dark-mode color scheme using natural green and gold accents that feels eco-friendly while maintaining web accessibility standards (WCAG).

Performance Optimizations

Performance measures incorporated to deliver instant loading speeds:

  1. Zero-Dependency Lightweight Build: Eliminated heavy JS frameworks to maintain lightning-fast render times on mobile devices.
  2. Optimized Web Font Loading: Preconnected and asynchronously loaded Cormorant Garamond typography to prevent render-blocking.
  3. Vercel Edge Analytics & Deployment: Leveraged edge caching and integrated Vercel Speed Insights to monitor real-world user metrics.

Conclusion

The Percava website successfully unites front-end web development with environmental advocacy. It serves as an effective digital extension for upcycled products, bridging consumer interaction, product innovation frameworks, and sustainable development awareness in an accessible digital environment.
